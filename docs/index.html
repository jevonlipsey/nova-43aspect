Quick guide

Android (DroidDeck / GameNative)

  1. Open the game's patcher on the handheld and pick the file from the game folder: Spel2.exe, Assembly-CSharp.dll or Celeste.exe.
  2. Save the patched copy over the original. Keep a .bak.
  3. In DroidDeck's display settings, set Resolution to Match screen (1280x960) and 16:9 game fit to Stretch. In GameNative, give the container the panel's native resolution.
  4. Fully exit and relaunch the app and the game.

Black bars after patching almost always come from the container's resolution, not the mod.

Native PC

  1. Open the game's patcher and patch the file from your game folder, or download the prebuilt files from the Releases page of the game's repo.
  2. Replace the originals in your game folder. Keep backups.
  3. Set the game to your display's native 4:3 resolution.

Steam's "Verify integrity" and game updates restore the original files. Re-patch after either.

Full install steps and troubleshooting are in each game's repo. Index source: jevonlipsey/nova-43aspect.
